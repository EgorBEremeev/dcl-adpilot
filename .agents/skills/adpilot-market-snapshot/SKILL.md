# Маркетинговый снапшот категории (`adpilot-market-snapshot`)

Скилл задаёт единый формат и быстрый порядок сбора рыночного снапшота для
выставления `default_price` карточки товара `<part_id>.yaml`.
Цель — **охват и наглядность**, а не исчерпывающий парсинг всех страниц.

## Имя и расположение файлов

Сохранять в поддиректорию `marketing_snapshots/` внутри папки категории тройку файлов:
```text
<category_path>/marketing_snapshots/category_marketing_snapshot_DD-MM-YYYY_HHMM.md
<category_path>/marketing_snapshots/category_marketing_snapshot_DD-MM-YYYY_HHMM.json  # сырые счётчики и кластеры
<category_path>/marketing_snapshots/category_marketing_snapshot_DD-MM-YYYY_HHMM.svg   # генерируется скриптом из .json
```
> **Важно:** никогда не перезаписывать предыдущий срез с другим временем — суффикс `_HHMM` нужен для истории наблюдений во времени.

## Обязательные измерения анализа

1. **Дискриминанта «Новые vs Б/У»:** всегда собирать цены не только на б/у (частные объявления), но и на новые аналоги (масс-маркет / реплики), так как цена нового задаёт психологический потолок для обычного б/у.
2. **География (2 опции):**
   - **С доставкой:** вся Болгария (`Цялата страна`).
   - **Лично (самовывоз):** г. Варна (`гр. Варна` и область).
3. **Товарные кластеры (с кодами для маппинга):** не усреднять весь рынок в одну цифру, а выделять кластеры по состоянию/типу с кодами:
   - `N1`, `N2`, ... — новые товары (масс-маркет, реплики, дизайнерские);
   - `B1`, `B2`, ... — б/у и реставрированные;
   - `P1`, `P2`, `P3` — наши ориентиры цены (быстрая продажа / баланс / с доставкой).
   Коды используются сквозным образом в матрице 2×2, инфографике и разделе «Товарные кластеры».

## Порядок сбора данных (OLX.bg через `chrome-devtools` MCP)

1. Открыть в изолированном браузере `chrome-devtools` MCP (не использовать личный профиль):
   - Запрос по ключевому названию товара по всей Болгарии (`/ads/q-.../`).
   - Тот же запрос по Варне (`/varna/q-.../`).
   - Более широкий категорийный запрос (например, материал/тип) по Варне и по стране.
   - Срез по категории с фильтром `Ново` (`?search[filter_enum_state][0]=new`).
2. Снять счётчики выдачи (`[data-testid="total-count"]`) и первые 30–50 карточек (`[data-cy="l-card"]`) через `evaluate_script`.
3. Сохранить датасет `<snapshot>.json` по схеме [dataset-schema.md](./references/dataset-schema.md) (счётчики `totals` и кластеры `clusters` с `count`) и сгенерировать квадратный SVG-график (`720×720`) скриптом:
   ```powershell
   py "<skill_dir>\scripts\render_snapshot_svg.py" "<snapshot>.json"
   ```
4. Проверить SVG в `chrome-devtools` на отсутствие XML-ошибок и наложений текста.
5. Заполнить отчёт строго по шаблону [snapshot-template.md](./references/snapshot-template.md), обязательно включив **оба** вида инфографики (текстовую ASCII-линейку и квадратный SVG), а в разделе 2 указать объём объявлений по каждому кластеру.
